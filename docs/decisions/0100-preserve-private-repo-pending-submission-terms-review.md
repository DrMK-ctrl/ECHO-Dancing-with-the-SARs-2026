# Preserve the private repository pending submission-terms review

**Date:** 2026-11-09  
**Status:** Open before NASA Space Apps submission

## Context

The project directive requires ECHO's repository and unfinished work to remain private unless the user explicitly authorizes release. NASA Space Apps' 2026 participant terms state that submission grants NASA broad permission to distribute a solution and that original content created for the challenge must be freely available or OSI-licensed. ECHO has been developed specifically in preparation for this challenge, so the scope of that requirement for pre-event code needs clarification.

## Decision

Keep the GitHub repository private and make no public release or license change unless the user explicitly authorizes it. Record organizer clarification and a project-lead release decision as prerequisites before submitting ECHO.

## Consequences

- Development and the private engineering record continue normally.
- Do not claim that private-repository submission is compliant or that ECHO is ineligible; the terms' application to pre-event work and the submission packaging route need confirmation.
- Before submission, identify which code, assets, data, and documentation are original, third-party, pre-existing, or created for the challenge, and apply the user's explicit release decision to any public materials.
