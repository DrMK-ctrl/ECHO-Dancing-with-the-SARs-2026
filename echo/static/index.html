ECHO · ABOUT THIS VIEW
Investigation before conclusion
ASF catalog footprints show metadata coverage only. For a selected GCOV observation and geographic area, ECHO can retrieve and map a bounded backscatter measurement window with its mask, processing source, and provider QA disposition. A QA-held preview is diagnostic only; no change or event interpretation is implied.
The optional NASA GIBS MODIS Terra true-color layer is optical geographic context for the selected acquisition date. It is not NISAR imagery or an analysis input. Its image request sends the displayed map bounds and date to NASA GIBS. Turn it off to use the coordinate grid alone.
We acknowledge the use of imagery provided by services from NASA's Global Imagery Browse Services (GIBS), part of NASA's Earth Science Data and Information System (ESDIS). NASA GIBS documentation
