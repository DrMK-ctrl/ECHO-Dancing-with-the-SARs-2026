ECHO · ABOUT THIS VIEW
Investigation before conclusion
This interface presents ASF catalog metadata. It currently has no SAR raster pixels, flood classification, or ground-validation layer. The mapped polygons are catalog footprints plotted on a longitude/latitude grid.
The optional NASA GIBS MODIS Terra true-color layer is optical geographic context for the selected acquisition date. It is not NISAR imagery, a SAR measurement, or evidence used by ECHO's analysis. Its image request sends the displayed map bounds and date to NASA GIBS. Turn it off to use the coordinate grid alone.
We acknowledge the use of imagery provided by services from NASA's Global Imagery Browse Services (GIBS), part of NASA's Earth Science Data and Information System (ESDIS). NASA GIBS documentation
